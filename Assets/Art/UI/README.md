# Menu art

- `menu_background.png` — oil-paint-stylized from the user's own Iceland
  photo (not a third-party/licensed asset; source photo isn't checked into
  this repo). Regenerate via `generate_menu_art.py`.
- `button_normal.png` — original button panel design (dark bevelled
  parchment/gold frame, gem accents), styled in the spirit of dark-fantasy
  game menus. Not copied from any specific game's actual artwork.
- `title_igu.png` — "Igu" rendered once to a bitmap with Georgia Bold, gold
  gradient, and glow. The font file itself is not checked into this repo
  (Georgia is a commercial font; shipping a pre-rendered PNG of text set in
  it is fine, shipping the `.ttf` would be redistributing it).
